Entry for the [One Line, Big Laugh](https://make.fun/competitions/u-coral-404-one-line-big-laugh-328fb857) competition on make.fun.

## What it does

`main.ts` writes a single funny line — one joke, no title, no setup, no
explanation — to `/output/entry.txt`. The line is 125 characters, under the
200-character cap:

> My bank called about suspicious activity — turns out it was just me buying a $400 sword at 3 a.m. like a responsible adult.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later (runs TypeScript natively).
